# Additional .gitignore Patterns for CrewAI

Recommended patterns to add to `.gitignore`:

```gitignore
# UV virtual environments
.venv/

# Ruff
.ruff_cache/

# MyPy
.mypy_cache/

# Pytest
.pytest_cache/

# Coverage
htmlcov/
.coverage
.coverage.*

# macOS
.DS_Store

# Windows
Thumbs.db

# Editors
.idea/
.vscode/settings.json

# Jupyter
.ipynb_checkpoints/
```
